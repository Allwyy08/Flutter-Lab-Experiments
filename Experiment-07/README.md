# Experiment 7 – Data Persistence using Google Cloud Firestore in Flutter

## 📌 Project Overview
**Student Records Management System** is a modern, responsive, and robust Flutter application designed to store and retrieve student information persistently using **Google Cloud Firestore**.

The application demonstrates real-time cloud data persistence with Flutter's official **`firebase_core`** and **`cloud_firestore`** packages. It establishes a reactive connection to the Firestore cloud database using **`StreamBuilder`**, stores records in a cloud collection named **`students`**, validates user input, handles loading and error states gracefully, and delivers persistent cloud storage accessible across browser sessions and device restarts.

## ☁️ Google Cloud Firestore Architecture

### Database Schema:
- **Collection Name:** `students`
- **Document ID:** Auto-generated by Firestore (`.add()`)

```json
{
  "name": "Allwyn",
  "register_number": "23CSE001",
  "department": "CSE (AI)",
  "created_at": "November 11, 2026 at 3:30:00 PM UTC+5:30"
}
```

### Firestore Service Methods:
- `addStudent({name, registerNumber, department})`: Calls `FirebaseFirestore.instance.collection('students').add({...})`.
- `getStudentsStream()`: Listens to `collection('students').snapshots()`, mapping documents to `Student` models sorted newest-first.
- `getStudentsOnce()`: One-time document fetch via `collection('students').get()`.

## 🛠️ Firebase Setup Guide

To connect the application to your Google Cloud Firebase project:

### Option 1: Automated Configuration with FlutterFire CLI (Recommended)
1. Log into your Google Firebase account:
   ```bash
   firebase login
   ```
2. Run FlutterFire CLI in the project directory:
   ```bash
   flutterfire configure
   ```
3. Select your Firebase project and enable **Web** (and Windows if desired).
4. FlutterFire CLI will automatically populate `lib/firebase_options.dart` with your real credentials.

### Option 2: Manual Configuration via Firebase Console
1. Open the [Firebase Console](https://console.firebase.google.com/).
2. Create a project (or select an existing one) and navigate to **Cloud Firestore**.
3. Click **Create Database** and start in **Test mode** (or configure read/write rules):
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /students/{document=**} {
         allow read, write: if true;
       }
     }
   }
   ```
4. Navigate to **Project Settings** > **General** > **Your apps** > Add **Web App** (`</>`).
5. Copy the configuration keys and paste them into `lib/firebase_options.dart`:
   ```dart
   static const FirebaseOptions web = FirebaseOptions(
     apiKey: 'YOUR_API_KEY',
     appId: 'YOUR_APP_ID',
     messagingSenderId: 'YOUR_MESSAGING_SENDER_ID',
     projectId: 'YOUR_PROJECT_ID',
     authDomain: 'YOUR_PROJECT_ID.firebaseapp.com',
     storageBucket: 'YOUR_PROJECT_ID.firebasestorage.app',
   );
   ```
